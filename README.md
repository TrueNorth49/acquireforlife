# acquireforlife.com

Static site for the Acquire app. Plain HTML and CSS, no build step. Deployed from this repo.

- `/` landing page
- `/support/` support page (App Store support URL)
- `/privacy/` privacy policy (App Store privacy policy URL)
- `/terms/` terms of use
- `assets/` logo files from the Acquire For Life logo guide, recoloured white and gold for the black background
